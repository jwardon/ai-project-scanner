# Security Policy

## Supported Versions

AI Project Scanner is currently in early development and does not yet have a supported release.

Security fixes will be applied to the latest version of the default branch until a formal release and support policy is established.

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository instead.

Please include enough information to understand and reproduce the issue where possible.

Security reports will be reviewed before information about a vulnerability is made public.
